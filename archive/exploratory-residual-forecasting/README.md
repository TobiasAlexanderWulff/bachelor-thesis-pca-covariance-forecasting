# Archiv: explorative Residualprognosen

Dieser Ordner bewahrt fruehere explorative Analysen auf, die neben dem
dominanten PCA-Indikator auch diagonale Residualkorrekturen oder
inferenzielle Zusatztests betrachtet haben.

Sie gehoeren nicht zum finalen Hauptumfang der Thesis. Der aktive,
schlanke Ablauf verwendet stattdessen:

1. eine feste PCA-Basis aus dem Trainingszeitraum,
2. den dominanten Indikator,
3. einen naiven Indikatorforecast und ARFIMA(0,d,0),
4. keine Residualkorrektur sowie
5. den direkten naiven Kovarianzforecast als Matrixbenchmark.

Die archivierten Dateien bleiben fuer nachvollziehbare spaetere
Nebenanalysen erhalten, duerfen aber nicht als Hauptresultate der Thesis
ausgegeben werden.
